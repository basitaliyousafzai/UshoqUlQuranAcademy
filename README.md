# Ushoq Ul Quran Academy - Official Website

A modern, responsive, high-converting website built for **Ushoq Ul Quran Academy** (Global Online Quran & Islamic Academy).

---

## 🌟 Key Highlights & Improvements Over Competitors:
1. **100% Original Content (Zero Plagiarism):** Custom tailored course syllabi, original mission/vision, and verified pedagogical structure.
2. **Interactive Multi-Currency Tuition Switcher:** Instant toggling across **USD ($)**, **GBP (£)**, **CAD (C$)**, **AUD (A$)**, and **EUR (€)** without page reload.
3. **Full Conversion Funnel:**
   - Quick Free-Trial lead capture widget on the homepage hero.
   - Comprehensive multi-step Admission & Registration page (`admission.html`).
   - Sticky WhatsApp Floating CTA with automated greeting message encoding.
   - Mobile Sticky Action Bar for smartphone users.
4. **Scholarly Transparency:** Dedicated pages for certified Male scholars and certified Female Ustadhas (for sisters and younger kids).
5. **Modern Islamic Aesthetics:** Custom Emerald Green (`#064e3b`) & Warm Gold (`#d97706`), typography using *Plus Jakarta Sans* and *Amiri* calligraphy.
6. **Built-in SEO & Performance:** Fully semantic HTML5 with complete meta descriptions, OpenGraph tags, and mobile responsive breakpoints.
